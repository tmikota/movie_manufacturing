# Why Unreal Initiatives Fail

## Tesler's Law

Larry Tesler (former VP at Apple) argued that every system has an inherent amount of complexity that cannot be removed—it can only be shifted.

When a production company buys software to "simplify" a workflow, they aren't eliminating the complexity of production tasks, software requirements, or number of pipelines needed.   They're moving the complexity.

In the case of Unreal engine - they're unknowingly doubling the complexity (at a minimum).

## We use Unreal Engine!

The promise of unreal engine to an executive is that "everything" can happen in Unreal Engine.   Every studio I work with has some flavor of this pattern:

What softare do you use at the studio?

Unreal Engine!

Everyone proclaims this in the first few days because everyone has been in meetings for months takling about how the studio will be moving to Unreal Engine.   And our language tends to lean toward simplicity, simply because it takes too long to describe the full system.

So then i ask each individual artist what software they use.

I typically come up with a list more like this:

## What's actually used

- Maya
- Blender
- Substance Painter
- Photoshop
- Adobe Premeire
- Resolve
- Houdini
- Nuke
- After Effects
- Fusion
- Shotgrid
- SyncSketch
- Excel
- Google Docs!

The complexity didn't change at all.  In fact - it grew.

As a simple example modelers now have to work in Zbrush, Maya (or blender), AND unreal engine.

So the modeler has to learn unreal engine - learn how to do everything they already know how to do in Maya and this doubles the amount of manual labor they already have.

In order to build a pipeline for the department in unreal engine - you have to have a pipeline for the department outside of unreal engine.  So the number of pipelines you have to have has increased quite a bit.   The next problem you're going to face is that people who know how to build pipelines in Unreal Engine are expensive.   So you're typically going to hire a basic developer that can write code.

This means that developer will have to build a few pipelines and fail a few times in order to know how pipelines should be designed and know how to work with artist.

### Time to train a developer to work in unreal for animation:

1 year with experienced mentorship.

3-5 years without mentorship.
