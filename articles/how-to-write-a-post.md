## Two ways to write

**In the browser.** Run `npm run dev`, then open [localhost:4321/keystatic](http://localhost:4321/keystatic). Click *Essays*, then *Add*, and write. Saving creates a Markdown file in `articles/`.

**In any editor.** Make a new `.md` file in `articles/` with the same block at the top as this file. The file name becomes the URL.

## Publishing

Untick *Draft* (or set `draft: false`), commit, and push. Drafts show up locally with a red badge and are never published.

> The structure from `notes/article-template.md` is a good starting point for a new essay.
